# Структура файлов данных (Dataset)

В данном каталоге содержатся исходные CSV-файлы с данными:

* **movies.csv** — содержит информацию о фильмах:
  * `movieId` — уникальный идентификатор фильма
  * `title` — название фильма и год выпуска
  * `genres` — жанры фильма (разделённые символом `|`)

* **ratings.csv** — содержит оценки, поставленные пользователями:
  * `userId` — уникальный идентификатор пользователя
  * `movieId` — идентификатор оцениваемого фильма
  * `rating` — оценка фильма по шкале от 0.5 до 5.0
  * `timestamp` — время выставления оценки в формате UNIX Timestamp

* **tags.csv** — содержит теги к фильмам, добавленные пользователями:
  * `userId` — идентификатор пользователя
  * `movieId` — идентификатор фильма
  * `tag` — текстовый тег
  * `timestamp` — время добавления тега

* **links.csv** — содержит идентификаторы фильмов в других сервисах:
  * `movieId` — идентификатор фильма из текущей базы
  * `imdbId` — идентификатор фильма на IMDb
  * `tmdbId` — идентификатор фильма на TMDb
